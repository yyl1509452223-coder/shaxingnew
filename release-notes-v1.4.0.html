v1.4.0

单机工具与修改器下载增强

当前推荐

这一版重点解决“能搜到、能下载、下载后能直接用”的问题，并把下载历史做得更接近真实文件管理。

  • 新增「单机工具」：接入 Game Cheats Manager 公共修改器库，支持按游戏名搜索修改器。
  • 支持 FLiNG 修改器来源解析与直链下载，减少跳转和手动查找。
  • 下载按钮实时显示百分比进度，支持暂停、继续、取消。
  • 下载完成后可直接打开文件；历史记录支持打开文件、打开所在文件夹和打开来源页。
  • 下载历史会实时检测本地文件是否存在，失效记录显示“已失效”并提供删除按钮。
  • 优化搜索相关性，减少无关结果；默认搜索页保持空白，只保留“输入游戏名”。
  • 修复 FLiNG 文件真实类型识别：优先读取 Content-Disposition 文件名和魔术字节，避免 EXE 被误保存为 ZIP。
  • 优化快捷键设置区收纳、未填色按钮样式、检查更新模块排序和标题不可选中。
  • 修复赛博朋克模式下“修改ID”和“选择头像”悬停预览文字看不清的问题。
