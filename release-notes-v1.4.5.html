v1.4.5

UI polish and game daily manager fixes

Latest

Shaxing v1.4.5 focuses on UI consistency and game daily management: a separate game daily manager window, fixed traffic-dot controls, solid rounded panels, custom confirmation dialogs, improved Pomodoro visuals, focus-app whitelist behavior, water reminder polish, cyber theme readability, and shortcut editing.

  • Game Daily Manager now opens as an independent window instead of an embedded panel.
  • Removed the extra outer frame and kept a solid rounded content panel for the manager window.
  • Fixed the red close dot, blue minimize dot, and manager list scrolling behavior.
  • Changed the Game Dailies title to a cleaner daily-game reminder.
  • Replaced native system confirm dialogs with Shaxing-styled rounded confirmation dialogs.
  • Improved Pomodoro icons, collapsed/hover animation, paused green-tomato state, and cyber theme display.
  • Focus app selection now uses the current running-app list with up to 7 whitelisted apps.
  • Non-whitelisted apps are covered by a blur mask during focus mode.
  • Water reminder popup now removes extra shadow/avatar blank area and centers the message.
  • Added shortcut editing entry and improved cyber theme contrast/readability.
  • Fixed multiple garbled labels, unclear button states, icon offsets, extra borders, and inconsistent shadows.
