## v1.4.0 更新重点

- 单机工具新增修改器搜索与下载。
- 下载过程支持百分比、暂停/继续、取消和完成后打开。
- 下载历史可打开文件/所在文件夹/来源页，并自动标记失效文件。
- 修复 FLiNG 下载文件类型识别，EXE 不再误存成 ZIP。
- 优化快捷键、更新模块、标题不可选中和赛博朋克悬停文字。
