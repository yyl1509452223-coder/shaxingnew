## v1.4.5 更新公告

### 1. 主要新增

- 每日游戏管理改为独立窗口，从主界面的“管理列表”打开，像单独工具一样管理游戏清单。
- 专注应用支持从当前正在运行的程序列表中选择，最多添加 7 个白名单应用。
- 专注倒计时期间，未加入白名单的应用会自动覆盖不可点击、可缩小的模糊蒙版。
- 设置页新增快捷键编辑入口，后续可以集中查看和调整快捷键。
- 番茄钟新增初始完整展示、3 秒后收起、鼠标悬停展开的交互；收起后仍保留时间。

### 2. 修复优化

- 修复每日游戏独立窗口的红色关闭点、蓝色最小化点无响应问题，并恢复下拉菜单可用性。
- 修复每日游戏弹窗多余外框、透明感过强、滚动和布局不统一的问题，标题统一为“每日游戏，别漏日活”。
- 修复番茄钟按钮看不清、图标错位、整体过大、阴影和多余内框问题；暂停时切换为青番茄状态。
- 修复喝水提醒弹窗的阴影、头像空白框和深色确认按钮，提示内容改为居中并统一为预览填色。
- 修复赛博朋克皮肤中文字对比度不足、番茄钟显示异常，以及多个问号乱码、状态不明显、圆角蒙版变方块等细节。
